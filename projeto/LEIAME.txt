  META-APRENDIZADO BASEADO EM EMBEDDINGS DE DATASETS
  Projeto de Implementação – TCC (UTFPR-CM)
  Versão 2.0 — Predição de Ranking com LOO + Spearman/Kendall
================================================================================

VISÃO GERAL
───────────
O projeto implementa um sistema de meta-aprendizado que, dado um novo dataset
de classificação, recomenda os melhores pipelines de aprendizado de máquina.

Fluxo principal:
  Dataset → Embedding (Dataset2Vec) → Preditor KNN/MLP → Ranking de Pipelines

Novidades da Versão 2.0 (vs. v1.0):
  ✔ Migração de classificação (Y_qual binário) para REGRESSÃO DE RANKING
  ✔ 100+ datasets (OpenML-CC18 + complementares, anteriormente 11)
  ✔ Preditor KNN multi-output via KDTree (equivalente a 60 modelos KNeighborsRegressor)
  ✔ Preditor MLP com loss BCE (Binary Cross-Entropy) para learning-to-rank
  ✔ Avaliação via Leave-One-Out (LOO) em vez de k-fold estratificado
  ✔ Métricas de ranking: coeficiente de Spearman (ρ) e Kendall's tau (τ)
  ✔ Matrizes X_emb e Y_accuracy persistidas para uso direto no preditor

COMO EXECUTAR
─────────────

1. Instalar dependências:
   pip install -r requirements.txt

2. (Opcional) Clonar o Dataset2Vec original:
   git clone https://github.com/hadijomaa/dataset2vec
   → Ajustar D2V_REPO_PATH em config.py
   → Sem ele, embedding estatístico de fallback é usado

3. Executar a Fase 1 (construção do meta-conjunto):
   python executar_fase1.py
   → Baixa 100+ datasets do OpenML (com cache automático)
   → Avalia 60 pipelines em cada dataset via CV-5
   → Salva X_emb.npy e Y_accuracy.npy para a Fase 2
   → Tempo estimado: horas (dependendo do hardware e nº de datasets)

4. Executar a Fase 2 (predição de ranking e avaliação):
   python executar_fase2.py
   → LOO com preditor KNN para k ∈ {1,3,5,7,10}
   → LOO com preditor MLP-BCE (requer PyTorch)
   → Seleciona automaticamente o melhor k pelo Kendall tau
   → Demonstração de recomendação para dataset holdout

5. Para análise interativa:
   jupyter notebook notebooks/


CONFIGURAÇÕES PRINCIPAIS (config.py)
──────────────────────────────────────
OPENML_TASK_IDS  → lista de ~120 IDs do OpenML (objetivo: 100+ válidos após filtro)
MIN_INSTANCIAS   → mínimo de instâncias por dataset (padrão: 500)
MAX_INSTANCIAS   → máximo de instâncias (padrão: 100000)
SCALERS          → [StandardScaler, MinMaxScaler, RobustScaler, None]  (4 opções)
SELECTORS        → [PCA, SelectKBest, None]                            (3 opções)
CLASSIFIERS      → [RandomForest, SVM, kNN, MLP, DecisionTree]         (5 opções)
CV_FOLDS         → número de folds na validação cruzada (padrão: 5)
KNN_K_RANGE      → valores de k avaliados no LOO (padrão: [1,3,5,7,10])
KNN_K_PADRAO     → k usado para recomendação final


PIPELINES (60 combinações = 4 × 3 × 5)
────────────────────────────────────────
Cada pipeline é a composição sequencial:
  Scaler (4) → Selector (3) → Classifier (5)

O preditor KNN atribui uma nota (acurácia estimada) a cada um dos 60 pipelines
para o dataset de consulta. O ranking é derivado ordenando os scores.


MÉTRICAS DE AVALIAÇÃO DO RANKING
──────────────────────────────────
Coeficiente de Spearman (ρ):
  Correlação de postos entre o ranking predito e o ranking real.
  ρ = 1  → predição perfeita da ordem; ρ = 0 → sem correlação.

Coeficiente de Kendall's tau (τ):
  Fração de pares de pipelines corretamente ordenados pelo preditor.
  τ = 1  → todos os pares na ordem correta; τ = 0 → acaso.
  Implementação: scipy.stats.kendalltau

Ambas as métricas são calculadas para cada fold do LOO e reportadas
como média ± desvio padrão.
